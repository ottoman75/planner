# 4X 플래너

시간 단위로 PLAN(계획)과 ACTION(실행)을 나란히 적고 체크하는 웹 플래너입니다.

**열기**: https://ottoman75.github.io/planner/

## 폰에 설치
- **iPhone**: Safari로 열기 → 공유 버튼 → **홈 화면에 추가** → 홈 화면 아이콘으로 실행
- **Android**: Chrome으로 열기 → 메뉴 → **앱 설치 / 홈 화면에 추가**

## 사용법
| 영역 | 조작 |
|---|---|
| 시간표 | 시간·분류·ACTION·PLAN 칸을 누르면 편집 시트가 열립니다. "위 칸과 합치기"로 여러 시간을 한 블록으로 묶고, 분류 블록을 SET으로 지정할 수 있습니다 |
| ✓ / 우선순위 | 누를 때마다 완료 토글 / 우선순위 1→2→3→없음 |
| 요약 | 달성률, 실행한 계획 수, SET 수, 카테고리별 계획 시간이 자동 계산됩니다 |
| FITNESS | 8주 프로그램: 날짜에 맞는 주차·단계·요일 유형과 세트별 목표(회색)가 표시되고, 실제 한 값을 입력하면 합계가 "실제/목표"로 나옵니다(목표 달성 시 초록). "편집"에서 시작일 변경·프로그램 끄기, 프로그램 밖의 날 운동 목록 관리. 수면·체중 기록 |
| HABITS | 눌러서 체크. "편집"으로 습관 추가/삭제 |
| NOTE | KEYWORD / IDEA / ETC 자유 메모 |
| 날짜 | ‹ › 로 이동, 날짜를 누르면 달력 |

## 알림 (⚙ 설정)
1. **알림 켜기** → 권한 허용 → **테스트 알림**으로 확인
2. 알림 시점: 정각 / 5·10·15·30분 전
3. 앱이 완전히 닫혀 있어도 받으려면 **캘린더로 내보내기**(.ics) → 캘린더 앱에 추가

## 폰 ↔ 맥 동기화 (⚙ 설정 → 기기 간 동기화)
1. **기록이 많은 기기에서 먼저**: "GitHub 토큰 만들기" 링크 → **gist** 권한만 체크 → Generate token → 토큰 복사
2. 동기화 칸에 붙여넣고 **연결** → GitHub 계정에 비공개 Gist가 하나 생깁니다
3. 다른 기기에서도 **같은 토큰**으로 연결 (연결된 기기에서 "토큰 복사" → 애플 기기끼리는 그대로 붙여넣기 가능)

이후로는 열 때, 수정할 때, 1분마다 자동으로 맞춰집니다. 알림 설정은 기기마다 따로입니다.

## 아이폰 캘린더 일정 가져오기 (⚙ 설정 → 아이폰 캘린더 가져오기)
기기 간 동기화가 먼저 연결되어 있어야 합니다.
1. 아이폰 **캘린더** 앱 → 하단 **캘린더** → 가져올 캘린더의 ⓘ → **공개 캘린더** 켜기 → **링크 공유 → 복사**
2. 플래너 설정의 캘린더 칸에 붙여넣기 (여러 개면 한 줄에 하나)
3. (최초 1회, 맥에서) 저장소 시크릿 등록: `gh secret set PLANNER_GIST_TOKEN -R ottoman75/planner` → 동기화에 쓴 토큰 붙여넣기

30분마다 GitHub Actions가 일정을 가져와, 오늘 이후 날짜의 **빈 칸**에 분류·ACTION·PLAN을 일정 시간만큼 블록으로 채웁니다(📅 표시). 직접 적은 칸은 그대로 두고, 이미 적은 칸에는 일정이 PLAN 아래 작게 보입니다. 손대지 않은 📅 블록은 캘린더 변경을 따라가고, ✓ 하거나 고친 블록은 내 기록으로 남습니다. "이 칸 비우기"로 지운 일정은 그 날 다시 채워지지 않습니다. 캘린더별 분류는 설정에서 바꿀 수 있습니다(기본: 회사 → ACTIVE, 그 외 LIFE).
공개 캘린더는 링크를 아는 사람이면 볼 수 있으니 링크를 공유하지 마세요.

## 데이터
- 동기화를 켜지 않으면 이 기기 브라우저에만 저장됩니다. 설정 → **백업 파일 저장 / 불러오기**로도 옮길 수 있습니다
- **기본 계획**을 저장해 두면 새 날짜를 열 때 자동으로 채워집니다. **전날 계획 불러오기**도 가능
